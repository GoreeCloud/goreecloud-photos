# GoreeCloud Photos — Branding

**Product name:** GoreeCloud Photos  
**Repository identifier:** `goreecloud-photos`  
**Design system target:** Glaze UI V1.5 / 1.5.1 current Stable  
**Branding status:** Product name established; repository-local final product artwork is not yet verified.

## Identity

The official product name is **GoreeCloud Photos**.

User-facing product surfaces should use the GoreeCloud Photos name consistently and should not present the product as a renamed third-party photo application.

## Visual direction

Photos is intended to be a media-first application. Glaze UI should:

- keep photographs and videos as the primary visual focus;
- use translucent or elevated navigation only when readability remains strong;
- support light, dark, and deep-dark presentation;
- support reduced effects, reduced motion, and reduced translucency;
- provide clear selection and system-state presentation;
- use adaptive backgrounds only where they do not reduce accessibility or misrepresent application state.

## Platform identities

Where applicable, product experiences may present verified state from:

- GoreeCloud Identity;
- Privacy Shield;
- Wardveil Security;
- Everkeep;
- GoreeCloud Manager;
- GoreeCloud Mesh;
- GoreeCloud Policy;
- GoreeCloud Observability.

Branding or icons must never substitute for actual runtime integration or evidence.

## Artwork status

No repository-local official Photos icon, logo, or artwork package is currently verified in this repository. Final visual assets must be established and validated before branding or production-readiness requirements are considered complete.
